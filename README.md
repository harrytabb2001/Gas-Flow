# Gas Flow
## Summary
Second lab experiment from my first year undergraduate in Physics at The University of Manchester. All data analysis was done in Excel so no .py files are included.

The aim of this experiment was to investigate the viscosity of Helium and Argon by measuring pressure differences along narrow tubes.  This was used to confirm fluid dynamics by comparing the calculated viscosities with values from literature.

## Technical Highlights
* Data Visualisation in Excel
* Linear Regression in Excel
* Chi-Square Analysis


## Files
* Gas Flow Lab Script.pdf contains a brief outline of the experiment given to me before I started.
* Gas Flow Lab Notebook.pdf contains my handwritten notes from during the experiment including a schematic diagram, key figures, snippets of the recorded data, calculations, data analysis and conclusions.
* Gas Flow Report.pdf contains my written lab report on the experiment.
